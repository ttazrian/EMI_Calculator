# 📱 EMI_Calculator

**EMI_Calculator** is a simple and user-friendly Android application for calculating the **Equated Monthly Installment (EMI)** for loans. It allows users to input loan amount, interest rate, and duration, and supports different payment frequencies.

## 🌟 Features
- **Loan EMI Calculation:** Enter loan amount, interest rate, and duration to calculate the monthly payment.
- **Flexible Payment Frequency:** Choose from Monthly, Bi-weekly, or Weekly payments.
- **User-Friendly Interface:** Clean, modern layout for easy use.
- **Dynamic Feedback:** Results are updated instantly when the Calculate button is pressed.

## 🔧 Tech Stack
- **Java** (Android)
- **Gradle** (Build system)
- **Android SDK**

1️⃣ Clone this repository:

```bash
git clone https://github.com/ttazrian/EMI_Calculator.git
````

3️⃣ Sync Gradle and build the project.
4️⃣ Run the app on an Android device or emulator.

## 💬 About EMI

EMI (Equated Monthly Installment) is the fixed payment amount made by a borrower to a lender at a specified date each month. This app helps users estimate their EMI based on loan details.
